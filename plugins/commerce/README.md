# @otwdesign/plugin-commerce

A shop for OTW CMS, as WooCommerce is for WordPress: products, a shop and product pages,
checkout, orders in the admin, and customers' orders on their account page. It comes with
"Pay later" (bank transfer or cash on delivery); payment gateways such as Stripe are plugins.

```sh
npm install @otwdesign/plugin-commerce
```

Add `"@otwdesign/plugin-commerce"` to `plugins` in the site's `cms.config.json`, restart or rebuild the site, and
activate it on the Plugins screen.

Part of [OTW CMS](https://github.com/OTWSRL/otw-cms), a WordPress-style CMS for Next.js and
PostgreSQL. Licensed under the Apache License 2.0.
