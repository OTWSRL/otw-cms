# @otwdesign/admin-ui

React components for OTW CMS admin screens, in the style of WordPress's admin: list tables,
postboxes, form fields, notices and buttons. Plugins build their own admin screens with them.

```sh
npm install --save-dev @otwdesign/admin-ui
```

Like `@otwdesign/sdk`, a plugin lists it as a peer dependency (`"@otwdesign/admin-ui": "^1.0.0"`).

Part of [OTW CMS](https://github.com/OTWSRL/otw-cms), a WordPress-style CMS for Next.js and
PostgreSQL. Licensed under the Apache License 2.0.
