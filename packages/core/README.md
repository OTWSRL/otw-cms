# @otwdesign/core

The kernel of OTW CMS: content and revisions, taxonomies, users, roles and capabilities, actions
and filters, media, mail, settings, migrations and the plugin loader, on PostgreSQL or the
embedded PGlite.

Sites don't install it themselves: `@otwdesign/next` brings it. Plugins import from
`@otwdesign/sdk`.

Part of [OTW CMS](https://github.com/OTWSRL/otw-cms), a WordPress-style CMS for Next.js and
PostgreSQL. Licensed under the Apache License 2.0.
