# @otwdesign/testing

Test a plugin for OTW CMS. `createTestKernel()` boots the CMS with your plugin on an in-memory
PostgreSQL (PGlite), signs people in and sends requests, with no server or database to set up.

```sh
npm install --save-dev @otwdesign/testing
```

Part of [OTW CMS](https://github.com/OTWSRL/otw-cms), a WordPress-style CMS for Next.js and
PostgreSQL. Licensed under the Apache License 2.0.
