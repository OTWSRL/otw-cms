# @otwdesign/next

OTW CMS on Next.js: the admin, the site's pages and templates, the plugin API routes, uploads, and
`withCms()` for `next.config.ts`.

Start a site with the scaffolder rather than installing this by hand:

```sh
npm create otw-cms@latest my-site
```

Part of [OTW CMS](https://github.com/OTWSRL/otw-cms), a WordPress-style CMS for Next.js and
PostgreSQL. Licensed under the Apache License 2.0.
